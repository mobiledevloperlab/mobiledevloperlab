## One workspace. The whole development loop.

**Explore → Edit → Run → AI → Debug → Review → Ship**

NimoteCode is for the moments when your desk is not nearby but your project is. Open a local folder or connect to the real machine over SSH; then edit code, run commands, inspect Git changes, use an AI agent, and ship the result without switching devices.

<p align="center">
  <a href="https://nimotecode.com">

</p>

| Develop where | Best for | What you get |
| --- | --- | --- |
| **Remote SSH** | Projects on a Mac, Linux machine, or VPS | Work directly against the host, services, and toolchains you already use |
| **Android Local Linux** | A Linux environment on-device | Root-free Ubuntu via PRoot with Bash, Git, and SSH on supported Android devices |
| **Local Workspace** | Projects already on your phone or tablet | Fast editing with the same editor, terminal, Git, and AI workflow |

## Built for more than a terminal

| Area | What you can do |
| --- | --- |
| **Editor** | Browse and search projects, edit code, and use LSP diagnostics for supported languages |
| **Terminal & Tasks** | Run commands and project tasks locally, in Android Local Linux, or through SSH |
| **Git** | Review status and diffs, browse history, then commit, pull, and push |
| **AI** | Work with the built-in project-aware agent, compatible ACP agents, or tools such as Claude Code and Codex on your own host |
| **Debug & Preview** | Debug code and preview web output, including HTML snapshots |

Android Local Linux is available on Android only. The app adapts to phones and tablets, with touch-first controls and external-keyboard support.

## Currently shipping

NimoteCode **1.2.2** is available on [Google Play](https://play.google.com/store/apps/details?id=com.nimote.nimotecode) and the [App Store](https://apps.apple.com/app/nimotecode-ssh-client-ide/id6776158253). Sign in during **Early Access Pro** to unlock all features at no cost for the current early-access period.

Recent releases have expanded split editor panes, in-app browser and media preview, Git history and Diff review, ACP agent support, and Android Local Linux. For the full, current change log, see the [release notes](https://nimotecode.com/releases/).
