## A mobile IDE built for real development.

**Explore → Edit → Run → AI → Debug → Review → Ship**

NimoteCode is a mobile SSH IDE and AI coding workspace for Android, iPhone, and iPad. Open a local or external project, connect to a Mac, Linux machine, or server over SSH, then edit code, run commands, review Git changes, collaborate with AI, and verify the result before you ship.

| Develop where | Best for | What you get |
| --- | --- | --- |
| **Remote SSH** | Projects on a Mac, Linux machine, or VPS | Work against the host, services, and toolchains you already use — including through SOCKS5 or HTTP CONNECT proxies |
| **Android Local Linux** | A Linux environment on-device | Run a root-free Ubuntu environment with Bash, Git, and SSH on supported Android devices |
| **Local Workspace** | Projects already on your phone or tablet | Open app-local or external folders with the same editor, terminal, Git, and AI workflow |

## Everything you need to finish the change

| Area | What you can do |
| --- | --- |
| **Editor & Explorer** | Browse, search, batch-manage files, and edit local or external project folders with touch and hardware-keyboard workflows designed for mobile |
| **Terminal & Tasks** | Run commands locally, in Android Local Linux, or over SSH; use configurable extra-key rows and send terminal output to AI when you need a second set of eyes |
| **Git** | See near real-time status, create and switch branches, review history and clear diffs, then commit, pull, and push without leaving the workspace |
| **AI collaboration** | Use the built-in project-aware agent, compatible ACP agents, or tools such as Claude Code and Codex on your own host — including follow-ups and interactive answers during an active run |
| **Plugins & panels** | Customize the workspace with plugins, panels, forms, workflows, artifact views, and script jobs for local or SSH targets, with permissions reviewed before changes apply |
| **Debug & Preview** | Debug code and preview web output, including HTML snapshots, so a mobile change can end with verification — not a guess |

Android Local Linux is available on Android only. NimoteCode adapts its touch-first controls, keyboard behavior, themes, and workspace layout to phones and tablets.

## Start building with NimoteCode 2.1.0

NimoteCode **2.1.0** (Build 59) is available for Android, iPhone, and iPad. [Get it on Google Play](https://play.google.com/store/apps/details?id=com.nimote.nimotecode) or [download it from the App Store](https://apps.apple.com/app/nimotecode-ssh-client-ide/id6776158253). Sign in during **Early Access Pro** to unlock all features at no cost for the current early-access period.

2.1.0 makes the workspace more consistent across phone, tablet, and desktop: choose appearance mode separately from the accent color, open workspace pages and Git history as editor tabs in landscape, and keep editor headers when returning from a fullscreen terminal. It also improves editor rendering, syntax highlighting, Git-diff typography, direct file search, Remote Explorer status, and mobile Agent and terminal controls.

The built-in Agent now searches large codebases and summarizes long files more efficiently, including files with very long or minified lines. Recent releases also added Plugin Center and customizable workspaces, continuous Agent collaboration, proxy-aware SSH, external-folder workspaces, recent-workspace resume, in-app update notices, shared Android Local Linux projects, configurable terminal controls, and batch Explorer actions. For the full history, browse the [release notes](https://nimotecode.com/releases/).
