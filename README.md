## Featured projects

### NimoteCode

**A mobile IDE for Android, iPhone, and iPad.** Edit local or remote projects, use an SSH terminal, review Git changes, and work with AI using your own provider. The built-in agent and Git write workflows are available through Early Access.

### NimoteShot

**An open-source App Store and Google Play screenshot generator.** Turn real app captures into editable, localized store artwork for iPhone, iPad, and Android. Design manually or use optional AI assistance; previews and exports render locally.

<p>
  <a href="https://github.com/mobiledevloperlab/nimoteshot">
    <img src="./assets/nimoteshot-framed.svg" alt="NimoteShot screenshot studio showing its editor and generated app store screenshots" width="100%" />
  </a>
</p>

**[Source](https://github.com/mobiledevloperlab/nimoteshot)** · [Quick start](https://github.com/mobiledevloperlab/nimoteshot#quick-start) · [Contribute](https://github.com/mobiledevloperlab/nimoteshot/blob/master/.github/CONTRIBUTING.md)

*Free and open source under AGPLv3 or later. Requires Python 3.11+. Cloud AI providers may charge for optional analysis.*
