## About

I'm **mobiledevlab**, an independent developer building tools that connect mobile development, remote workspaces, and AI coding agents. My focus is practical software with clear interfaces: a workspace to write code, a host runtime to keep work running, and a screenshot studio to prepare apps for launch.

Previously at **Huawei** · Graduate of **Southwest Jiaotong University**

## Featured projects

### NimoteCode

**Your development workspace on Android, iPhone, and iPad.**

Bring code editing, remote access, Git, and AI assistance into one mobile IDE.

- **Edit and navigate** local or remote projects from your phone or tablet.
- **Connect over SSH** to work with remote files and an interactive terminal.
- **Review Git changes** and collaborate with AI using your own provider.
- **Pair with NimoteHost** for host-side tasks, terminals, and coding agent sessions in compatible versions.

### NimoteHost

**Keep tasks, terminals, and coding agent sessions running after clients disconnect.**

The open-source host companion to NimoteCode, with a standalone CLI and desktop manager for Linux, macOS, and Windows.

- **Continue work across disconnects** with host-side tasks and terminal sessions.
- **Access sessions and agent approvals** from compatible NimoteCode versions over an existing SSH connection.
- **Use it independently** through the desktop manager, RPC, or compatible MCP clients.
- **Run on your own infrastructure** without a Nimote account or public relay.

**[Source](https://github.com/mobiledevloperlab/nimotehost)** · [Releases](https://github.com/mobiledevloperlab/nimotehost/releases) · [Getting started](https://github.com/mobiledevloperlab/nimotehost#start-here)

*Open source under Apache-2.0. Configure SSH and third-party agent CLIs separately. Session persistence covers client disconnects; restarting Host or the OS does not restore task processes.*

### NimoteShot

**Turn real app captures into App Store and Google Play screenshots.**

An open-source screenshot studio for creating editable, localized store artwork for iPhone, iPad, and Android.

- **Start with real captures** and arrange them into store-ready layouts.
- **Refine copy and localization** manually or with optional AI assistance.
- **Preview and export locally**, with editable project files for future updates.
